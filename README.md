# Pilates Studio — Demo pubblica

Demo interattiva dell'app di prenotazione lezioni Pilates. Tutta l'app gira nel
browser con dati simulati (localStorage): nessun backend, nessun dato reale.

**Prova la demo:** https://flavietto15.github.io/pilates-app/

> repository privato `pilates-app1`. Questa pagina è generata con
